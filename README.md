# 📒 Sistema de Agenda em C

Um sistema de agenda desenvolvido em **C** para praticar conceitos fundamentais de programação, como estruturas de dados, funções, entrada e saída de dados e manipulação de informações.

## 🚀 Funcionalidades

O sistema permite:

* ➕ **Cadastrar contatos**
* 🔍 **Buscar contatos**
* 🗑️ **Remover contatos**
* 📋 **Visualizar contatos cadastrados**

## 🛠️ Tecnologias utilizadas

* **C**
* **GCC** — compilador
* **Git/GitHub** — versionamento e armazenamento do projeto

## 📚 Objetivo

Este projeto foi desenvolvido como parte dos meus estudos em **Ciência da Computação**, com o objetivo de praticar lógica de programação e os fundamentos da linguagem C.

**Projeto desenvolvido para fins de estudo e prática em C.** 💻
